# Security Policy

## Supported Versions
Only the latest release of Codex Agent Engineering receives security patches.

| Version | Supported |
| :--- | :--- |
| `0.1.x` | Yes |
| `< 0.1.0` | No |

## Reporting a Vulnerability
If you discover a potential security vulnerability (e.g. prompt injection bypass in skills, sandbox breakout risk, or malicious payload vectors in benchmark tasks), please report it responsibly.

**DO NOT FILE A PUBLIC ISSUE.**

Email security disclosures to: `security@codex-agent-engineering.org` (or contact project maintainers privately via GitHub Security Advisories). We will acknowledge receipt within 48 hours and provide a coordinated disclosure timeline.
